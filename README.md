# Deep Learning Practicals

A collection of 18 Jupyter Notebook implementations covering fundamental and advanced concepts in Deep Learning, Neural Networks, CNNs, and Object Detection.

## 📚 Practicals Overview

| Practical | Topic | Experiments |
|---|---|---|
| 1 | MNIST Classification | MLP, Logistic Regression, Decision Tree |
| 2 | Activation Functions | Sigmoid, Tanh, ReLU, Leaky ReLU, ELU |
| 3 | Gradient Problems & Regularization | Weight Initialization, Dropout, Early Stopping, Normalization |
| 4 | CNN Architectures | CNN Hyperparameters, LeNet, AlexNet, VGG16, ResNet50 |
| 5 | Advanced CNN Concepts | ResNet50 Transfer Learning, Feature Maps, Filters |
| 6 | Object Detection | R-CNN, Fast R-CNN, YOLO, SSD MobileNet |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sohamshinde25/Deep-Learning-Practicals.git
```

### 2. Navigate to the project

```bash
cd Deep-Learning-Practicals
```

### 3. Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install dependencies

Install the required libraries according to the notebook you want to execute.

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow torch torchvision ultralytics jupyter
```

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any practical notebook and execute its cells sequentially.
